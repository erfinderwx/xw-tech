底盘轮毂电机更换与系统配置说明

更换轮毂电机后，必须根据新电机的备件号，在机器人系统中正确修改 字段 13：motorVersion。本文提供两个修改入口及带点击标注的界面截图。

适用：6.5 寸 Maxwell（M）电机 适用：6.5 寸中菱电机 两个入口任选其一
!
保存后必须重启机器人

字段修改并保存后不会立即生效。必须重启设备，新的电机配置才会生效。

Overview

操作总览

先完成机械更换，再按备件号识别电机，最后从任一系统入口修改字段、保存并重启。

1关闭电源并更换电机
2核对新电机备件号
3选择入口一或入口二
4修改字段 13
5保存并重启设备
6低速测试并确认

机械更换

轮毂电机的拆卸和安装，请按照普渡学院官方底盘拆装视频操作。

开机前检查

  • 左右两侧驱动电机型号一致
  • 电机线束及接插件安装到位
  • 紧固件已固定，线束无挤压干涉
  • 只修改 motorVersion，不要修改其他字段

Identify first

先用备件号识别电机

两种电机均为 6.5 寸，不能只看轮毂尺寸。请以新电机的备件标签、包装标签或领用记录为准。

备件号 电机类型 配置字段 填写值
19999-000848 Maxwell 电机（M 电机） (13) motorVersion 5
19999-000300 6.5 寸中菱轮毂电机 (13) motorVersion 3

字段说明：motorVersion 是 Machine Info 中的第 13 个字段，用于配置机器人底盘当前安装的驱动轮毂电机类型。更换电机后，必须按新电机备件号填写对应值。

选择原则：以新安装电机的备件号为准；不要参考旧电机型号，也不要直接沿用系统原有字段值。

入口一 · Debug → Hardware

通过 Hardware 修改

Debug› Hardware› MachinInfo · Open› 字段 13› SAVE› 重启
  • 红色：点击入口
  • 绿色：填写字段
  • 蓝色：保存
1

在 Debug 界面点击 Hardware

在页面左下方找到 DebugHardwareAndSensor 区域。

2

在 Hardware 页面打开 MachinInfo

找到左侧的 MachinInfo 区域，点击右下角的 Open。

3

修改字段 13 并保存

找到 (13) motorVersion，按备件号填写 5 或 3，然后点击右上角 SAVE。

入口二 · Debug → RunToMappingTool

通过建图工具修改

Debug› RunToMappingTool› 齿轮› Ändern Sie MachineInfo› 字段 13› Speichern› 重启
1

从 Debug 打开建图工具

在右侧 Tools 区域点击 RunToMappingTool。

2

点击地图列表页面的齿轮

进入地图列表页面后，点击页面底部的齿轮图标；当前截图中位于左下角。

3

打开 Ändern Sie MachineInfo

在设置页面向下找到 Ändern Sie MachineInfo，点击该行。

4

修改字段 13 并保存

找到 (13) motorVersion，按备件号填写 5 或 3，然后点击右上角 Speichern。

Apply & verify

保存、重启与检查

无论使用哪一个入口，最后都必须完成保存和重启。

① 保存 入口一点击 SAVE；入口二点击 Speichern。
→
② 重启机器人 完整重启设备后，新的 motorVersion 配置才会生效。

重启后的确认项目

  • 重新进入 Machine Info，确认字段 13 已正确保存
  • 确认左右两侧驱动电机型号一致
  • 在平整、空旷区域进行低速直行测试
  • 测试后退、左转、右转和停止
  • 系统无电机或底盘相关故障提示
  • 机器人无明显跑偏、抖动、异响或驱动无力

异常时优先检查

字段是否选错

19999-000848 应为 5；19999-000300 应为 3。

配置是否已生效

确认已点击保存，并在保存后完整重启机器人。

硬件是否安装到位

检查左右电机型号、接插件、线束和紧固件。
